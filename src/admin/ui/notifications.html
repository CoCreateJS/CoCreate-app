Toastify JS

You can use plugin="Toastify" with data-toastify (as a JSON object for all options), or use individual data-toastify-* attributes to define each option separately.

Display Position
Offset Position
Close icon Display
Duration
<!-- Toastify with JSON options -->
<button type="button" plugin="Toastify" data-toastify='{"text":"Welcome Back! This is a Toast Notification","gravity":"top","position":"right","className":"bg-primary","duration":3000,"close":true}' class="btn btn-light w-xs">JSON Options</button>

<!-- Toastify with individual options -->
<button type="button" plugin="Toastify" data-toastify-text="Welcome Back! This is a Toast Notification" data-toastify-gravity="top" data-toastify-position="right" data-toastify-className="bg-primary" data-toastify-duration="3000" data-toastify-close="$true" 								 class="btn btn-light w-xs">Individual Options</button>
