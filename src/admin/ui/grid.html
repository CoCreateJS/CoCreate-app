Flexible Layout Options

Combine flex, wrapping, gap, and width utilities to build responsive layouts without a row-and-column grid.

Purpose Classes Behavior
Layout container d-flex flex-wrap gap-4 Wraps items naturally with consistent spacing.
Flexible item w-300 flex-grow-1 Starts near 300px and grows into available space.
Wide flexible item w-400 flex-grow-1 Starts near 400px for cards and larger controls.
Full-width item w-100 Occupies the complete flex line.
Content-sized item w-auto flex-shrink-0 Uses its content width without shrinking.
Axis spacing row-gap-* / column-gap-* Adjusts vertical and horizontal spacing independently.

Vertical alignment (align-items-start)

Use align-items-start class to vertically align-items at the start.

w-300 flex-grow-1
w-300 flex-grow-1
w-300 flex-grow-1 
<!-- Vertical alignment (align-items-start) -->
<div class="d-flex flex-wrap gap-4 align-items-start">
    <div class="w-300 flex-grow-1">
        ...
    </div>
    <div class="w-300 flex-grow-1">
        ...
    </div>
    <div class="w-300 flex-grow-1">
        ...
    </div>
</div>

Align Self

Use the align-self-start,align-self-center, or align-self-end class respectively to vertically align items with a different position.

align-self-start
align-self-center
align-self-end 
<!-- Align Self -->
<div class="d-flex flex-wrap gap-4">
    <div class="align-self-start w-300 flex-grow-1">
        ...
    </div>
    <div class="align-self-center w-300 flex-grow-1">
        ...
    </div>
    <div class="align-self-end w-300 flex-grow-1">
        ...
    </div>
</div>
